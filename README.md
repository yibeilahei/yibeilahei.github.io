# Lazahata

Browser-only EPUB → XTCH converter for Xteink / CrossPoint e-readers. Next.js app that **exports a static site** — no server, no uploads.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm test
```

## Build a static site

```bash
npm run build
```

Output is written to `out/`. Preview it with:

```bash
npm start
```
